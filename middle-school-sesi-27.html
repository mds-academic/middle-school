Tag harus sama persis

Contoh: buku_rahasia dan buku-rahasia adalah dua tag berbeda. Saat kamu menyimpan dengan satu nama lalu membaca dengan nama lain, data yang dicari tidak ditemukan. Value adalah isi dari tag tersebut. Nilai default hanya digunakan oleh GetValue ketika tag yang diminta belum ada; nilai default tidak otomatis disimpan ke TinyDB.

Kenapa ClearTag wajib?

Tombol Hapus harus mengerjakan tiga hal. Pertama, ClearTag menghapus isi tag buku_rahasia dari TinyDB. Kedua, txtCatatan.Text dikosongkan agar tidak tampak input lama. Ketiga, lblHasil.Text kembali ke pesan awal. Kalau kamu hanya menghapus tulisan dari TextBox atau Label tanpa ClearTag, catatan lama masih mungkin muncul lagi ketika GetValue dipanggil.

ClearTag("buku_rahasia") menghapus data yang tersimpan pada tag tersebut. Ia bukan perintah untuk menghapus seluruh proyek MIT App Inventor. Setelah ClearTag, panggilan GetValue berikutnya akan memperoleh nilai default jika tidak ada nilai baru yang disimpan. Inilah mengapa tombol Hapus perlu diperiksa lagi setelah aplikasi dibuka ulang.
